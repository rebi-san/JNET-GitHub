## Whale animation overflow (0.221)

At `9ec80`, Decoration animation tracks use a 16-byte name at `+5a0`, then a 32-bit cached index at `+5b0`, with four tracks of stride `44`. The free-slot path `9ee80..9ee8c` copies the name through its terminator without bounds and leaves the cached index intact. `JNETCharacter_WingSpin` overwrites the index with `7053676e`; the user fault registers report this exact index at `9d779`, which writes through `decoration+588 + index*80 + 12`. All private MeshAnimation resource keys and target references now use bounded `JC_` aliases; mesh/shader namespaces are unchanged. Regression checks cover the offending bytes, alias length rejection, declaration/reference consistency and unmodified animation payloads. Live correction remains unverified.
